About This Project

The Placement Prediction System is a Machine Learning application designed to help students understand their chances of getting placed during campus recruitment.

By analyzing historical placement data, the system provides an estimated prediction, helping students focus on areas of improvement.

Technologies Used:

  • Backend: Python, Flask
  • Data Processing: Pandas, NumPy
  • Frontend: HTML5, CSS3, Jinja2
  • Machine Learning: Scikit-Learn
